# 🎮 无欲物语 (astrbot_plugin_wywy)

> 多功能群聊小型娱乐综合插件，集成魔改高能军火轮盘赌、Roguelike命格异能抽奖、战场突发战术道具与海量热梗文案！支持每个群独立管理与配置隔离！

---

## ✨ 核心特性

### 1. 🔫 魔改军火库（四大武器体系）
- **经典左轮**（`/装填 [左轮]`）：标准 6 孔弹巢决斗，单发判定，经典心跳博弈。
- **巴雷特大狙**（`/装填 大狙`）：高爆穿甲，禁言时间翻倍，**35% 几率触发【穿透】**，连带后排围观路人一同送进小黑屋！
- **加特林机枪**（`/装填 加特林`）：15 发大弹鼓，一息三千六百转！**单次扣动直接疯狂 3 连扫射**，多发实弹禁言叠加！
- **RPG火箭筒**（`/装填 火箭筒`）：艺术就是爆炸！一旦引爆，**80% 几率产生【AOE冲击波】**，拉上群内路人同归于尽！

### 2. 🌟 开局命格异能抽奖（Roguelike 词条）
- **持久化模式切换**：群管理员发送 `/轮盘模式 能力` 或 `/轮盘模式 普通`，群模式自动落盘持久保存，换局重启不丢失。
- **能力模式下专属神技**（发送 `/抽能力` 觉醒）：
  - **【极意·闪避拉满】(SSR)**：闪避率飙升至 40%，残影绝活哥！
  - **【义父救我】(SSR)**：中弹瞬间扑通跪地大喊义父，60% 几率强行抓取路人替死！
  - **【弹反大师 Parry】(SSR)**：平底锅护体！30% 几率完美弹刀反弹子弹击中装弹者！
  - **【锁血挂壁】(SR)**：名刀司命！强制免疫第一次致命中弹！
  - **【原地核爆】(SR)**：倒地引爆全身手雷拉路人一起升天！
  - **【嘴硬王者】(SR)**：禁言时间直接减半，倒地前触发最硬遗言！
  - **【曼波透视眼】(SR)**：提前私下偷窥下一发是实弹还是空弹！
  - **【疯狂星期四】**、**【专业碰瓷】**、**【五五开虚张声势】**、**【手抖连击】**、**【纯真非酋体质】** 等！

### 3. 💣 战场突发战术道具（开枪后随机空投）
- **粘性炸弹**：机器人恶作剧扔出粘弹黏在开枪者身上，启动 **击鼓传花** 倒计时！接下来开枪的人会依次继承炸弹，倒计时归零轰然引爆！
- **战术烟雾弹**：全场白茫茫，进入烟雾迷障战术掩护！
- **强光闪光弹**：致盲全场，下一位开枪者闪避率归零且手抖！

### 4. ⚙️ 群独立管理与隔离系统
- 每个群拥有完全独立的配置档案，群管理员可自主配置本群开关、玩法模式、禁言时长区间、道具开关等，互不干扰！
